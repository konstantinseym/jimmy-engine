# Jimmy Engine

A modern personal blog project built with React, Supabase, TanStack Query, and Tailwind CSS.

Jimmy Engine is a portfolio project focused on building a clean, responsive, and interactive blog experience with authentication, comments, pagination, animated UI, and server-state management.

## Overview

Jimmy Engine is a full-stack blog application designed as a personal publishing interface. The project combines a modern frontend with a Supabase backend, using PostgreSQL, authentication, RPC functions, and Row Level Security.

The main focus of the project is not to create a reusable blog engine, but to demonstrate practical frontend architecture, backend integration, and product-level UI decisions in a real application.

## Key Functionality

* Responsive blog layout
* Landing page with hero section
* Blog post previews
* Single post pages
* Google authentication
* Comment system
* Paginated content loading
* Animated route and UI transitions
* Server-state handling with TanStack Query
* Supabase integration with PostgreSQL and RPC functions

## Architecture Focus

The project is structured around reusable UI components, feature-based sections, API abstraction, and server-state synchronization.

TanStack Query is used to manage remote data such as posts, comments, metadata, loading states, errors, pagination, and cache invalidation.

Supabase is used as the backend layer for authentication, database access, PostgreSQL functions, and security rules.

## Project Purpose

This repository is part of my web development portfolio. It was built to demonstrate my ability to design and implement a modern full-stack web application using a frontend-first workflow with real backend integration.

The project reflects practical work with React architecture, routing, authentication flow, database-backed features, asynchronous state, and UI polish.
